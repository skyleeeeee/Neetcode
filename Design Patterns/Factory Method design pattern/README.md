# Py-Logger-Factory

A small Python library demonstrating the Factory Method pattern for loggers.  
Supports writing to files, PostgreSQL, or a remote HTTP service, all via a common interface.

## Installation

```bash
git clone https://github.com/your-username/py-logger-factory.git
cd py-logger-factory
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
